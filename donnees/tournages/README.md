# donnees/tournages/

Une déclaration JSON par projet (un projet = un tournage = un ou plusieurs dossiers de
`video-projects/`). Tu n'as rien à écrire à la main : un dossier de `video-projects/`
apparaît tout seul dans le hub (badge « à vérifier »), et la première modification faite
dans le hub (titre, validation, publication) écrit son fichier ici.
